# 自动参考图选择：当前发现与两张源图消融方案

## 1. 当前结论

自动选择8张参考图后，TP b0–b6在val100上的七组固定路线平均Dice全部提高，候选Oracle也提高，但原独立Router的最终选中Dice下降。因此目前有两个需要分开研究的问题：参考图怎样自动选择，以及候选选择器怎样适应参考图变化。

“使用频率高”不等于“仅保留这些图就足够”。下一步用自动8张中使用最多的两张重新生成完整候选池，直接检验少数高频源图是否已提供主要收益。

本文件记录已完成结果，并定义下一步实验；文件生成时两张源图实验尚未启动。

## 2. 数据和评估口径

- 固定原train800 / val100 / test100划分，不重新划分数据。
- 原方案：train内固定8张GT作为参考，792张为无标注目标。
- 自动选图：仅根据train800的冻结SAM3-base图像特征选择；所有自动/随机名单冻结后才读取所选样本GT。
- 选图使用1008尺度图像特征；为保持原TP对照，路径检索特征与传播画布沿用256。
- TP为SAM3-base、patch_mean KNN、beam width 32、每目标b0–b6七条候选链；参考GT用于前景原型、初始化框及返回一致性。
- 当前分割结果全部来自val100；Dice在256分辨率按图计算后取平均。没有新test结果。
- 原独立Router保持冻结，未因新参考图重新拟合。它曾使用同一val100拟合，因此本轮Router结果是开发集描述性对照，不是独立泛化评估。
- 微调后的SAM3单图直接预测与本文件讨论的TP传播是不同实验环节。

## 4. 自动选图首轮实验

对800张train，采用贪心覆盖选择：每次加入使全体训练图像与最近参考的平均相似度增加最多的图像。比较整图特征与整图＋局部特征；后者综合整图余弦和局部视觉词直方图余弦，两者权重各0.5。

局部词典完全由train图像patch拟合，不使用GT或伪mask。算法排除完全相同文件的重复候选，但尚未实现可靠的同病例/视频近重复排除，不能保证语义上完全不重复。

|方案：8张预算|综合特征覆盖|
|---|---:|
|原8张|0.835373|
|随机100组均值|0.830501|
|自动：整图特征|0.839891|
|自动：整图＋局部特征|0.852560|

覆盖指标在排除所选图像自身后的792张上计算，不是Dice，也不是独立于选择目标的验证指标。

综合方案保留原8张中的1张，另选7张；冻结后GT面积占比为1.71%–22.72%，中位数10.35%。可以看到更大、细长及部分截断的目标，但仍以明显隆起外观为主，不能视为完整形态覆盖。

预设的特征覆盖收益停止规则在综合方案第11张触发：连续3次新增收益低于单张参考剩余平均距离的1%。这只是探索性停止规则，不证明11张是分割任务的最低标注需求。

## 7. 下一步：只保留高频两张，重新生成TP候选

### 7.1 冻结的两张源图

1. 自动04：`kvasir-seg::cju5vi4nxlc530817uoqm2m7a`。
2. 自动06：`kvasir-seg::cju8dpa89u6l80818dj6lldh9`。

选择规则为已完成自动8张实验中，全部700条候选链的源头使用次数前二，不依据Dice排序。按最终Router使用次数排序，前二也是相同两张。

### 7.2 重跑方式

- 将允许的标注源头从自动8张缩减为以上2张。
- 桥接候选仍为原train800的RGB图像；其余参考图可作为普通桥接图，但其GT不参与两源图条件下的原型、提示或返回评分。
- 保持原val100、b0–b6、beam32、检索/传播尺度256、SAM3-base及冻结Router不变。
- 为每个val目标重新搜索七条完整路线并冻结，再进行前向和返回传播；不是删掉旧结果里来自其他六张的链后直接平均。
- 相同设置下允许复用经过路由ID、初始化、输入文件及模型一致性核验的完全相同路线推理缓存；改变的路线必须重新推理，并记录复用/重算数量。
- 始终对完整val100报告结果；不因某些目标质量低而剔除。
- 输出固定b0–b6 Dice、Oracle、冻结Router Dice、Oracle差距、两源头分布、逐目标得失及其是否原本依赖其余六张参考图。
- 本轮先不重拟合Router，避免同时改变参考数量和选择器。若适配Router，另做按目标分组的交叉验证实验。

### 7.3 如何解释

- 若两张的Oracle和各固定路线基本保持：说明这两个高频源头对当前val有较强代表性，值得继续研究参考集压缩。
- 若Oracle明显下降：说明低频参考图可能对少量困难目标提供关键补充，不能仅凭低使用率删除。
- 若Oracle保持而Router改变明显：需要分析候选评分和路径特征分布的变化。
- 应预先设定“基本保持”的容忍范围，并结合配对差值区间；不能事后选择最有利的桥接数或阈值宣称两张足够。

### 7.4 标注预算与开发集限制

本方案是“用8张建立系统后，保留其中2张作为活动参考”的压缩消融。前期发现高频两张时已经用过8张GT，因此不能把整个过程宣称为只花费2张标注的实验。

两张源图的筛选还利用了val图像上的使用情况。虽然没有按val Dice挑选，重跑同一val仍属于开发集探索，不能作为独立泛化证据。

若要严格研究“只需标注两张”，应另外用train RGB特征直接冻结2张名单，再只开放这2张GT；不能依赖8张标注传播后的使用次数。最终选择规则须在train内确定，再以冻结的val/test协议评估。
