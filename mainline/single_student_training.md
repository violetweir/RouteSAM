# 单学生 S：已确认的训练配方

状态：用户已授权实验，标签与预检查已完成，硬/软两组训练已启动。实际执行配置见 [single_student_experiment.md](single_student_experiment.md)。

## 已确认设置

| 项目 | 设置 |
|---|---|
| 学生 | S2/S3 合并为一个学生 S，沿用 U-Net |
| 数据划分 | 沿用原划分及有无标注身份 |
| 本阶段训练集 | 8 张真标注图 + 580 张伪标签图，共 588 张 |
| 采样 | 全部图像进入同一个数据集，每个 epoch 随机打乱并完整遍历一次 |
| 重复采样 | 不为 GT 或伪标签设置固定 batch 配额，不做额外 GT 重采样 |
| Batch size | 12 |
| 每轮迭代数 | 588 / 12 = 49 |
| Epoch 数 | 816 |
| 总迭代数 | 816 × 49 = 39,984，约等于原 40,000 iter |
| 样本权重 | 所有图像均为 1 |
| 像素权重 | 本版不引入置信度加权或额外忽略区域 |
| 伪标签额外系数 | 取消原 0.5 系数 |
| 伪标签权重渐增 | 取消原 pseudo ramp |
| 损失 | 每张图分别计算 BCE + Dice，再对 batch 中所有图像取平均 |

## 等权损失的含义

统一目标为：

`L = mean_over_images(BCE_i + DiceLoss_i)`

GT 图使用真实标签，伪标签图使用生成的监督标签；损失不按标签来源分别求均值后加权，也不再用 q_multi 在训练池内归一化生成图像权重。Dice 应按图像计算后平均，以保持这里约定的逐图等权口径。

不对图像额外重采样时，每张 GT 图与每张伪标签图每个 epoch 各出现一次，816 epoch 各出现 816 次。多数 batch 没有 GT 属于这一统一采样方案的正常情况，训练代码不得再假设前若干张必定是 GT。

## 已确认的监督标签

主方案为 `Y = 0.75*M + 0.25*P`：M 为 Router 在合格候选中选出的主 mask，P 为返回一致性合格候选的等权平均。保留 `Y=M` 作为硬标签对照，其他训练设置一致。详见 [pseudo_label_construction.md](pseudo_label_construction.md)。正式标签已生成并核查，硬/软对照训练已启动。
