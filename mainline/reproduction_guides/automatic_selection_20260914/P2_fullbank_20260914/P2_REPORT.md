## 结果 2：宽度杠杆在 Kvasir 上显著且单调（全深度）

原始排序下，相邻 k 的天花板提升（配对 bootstrap）：

| 区间 | validation | test |
|---|---|---|
| k=1→2 | **+0.0370** [+0.015,+0.066] | **+0.0148** [+0.007,+0.025] |
| k=2→3 | +0.0063 [+0.002,+0.015] | +0.0104 [+0.002,+0.022] |
| k=3→5 | +0.0072 [+0.002,+0.017] | +0.0093 [+0.005,+0.015] |
| k=5→8 | +0.0058 [+0.002,+0.010] | +0.0017 [+0.001,+0.003] |

**全部显著为正，但迅速递减**，与 P2 命题一致（`H_k ⊆ H_{k+1}` ⇒ Oracle 单调）。

**深度会替代宽度**：同一个 k=1→2 的增益，在仅 b0 时是 +0.069（test），在全深度时只剩 +0.015。
即"多给深度"和"多给样板"在抬天花板这件事上互相替代。

## 结论

1. **三个杠杆——校准、宽度 k、深度 m——互相替代**，都在扩大"有效证据"。
   在 Kvasir 上：校准 0、宽度显著但递减、深度替代宽度。
   在 BUSI 上：校准显著（高偏置）、宽度显著。这是同一条规律的两端。
2. **校准的有效性由偏置比门控**现在有两个全深度数据点（BUSI 5.42 → 显著；Kvasir 0.68 → 无效），
   加上三个 b0 点（1.10 → 不显著），规律成立。
3. **1% 预算偏保守**：单张标注的全深度天花板已达 0.9142。
4. 论文图 4 现在有**两个全深度数据集**，不再依赖 BUSI 单点。
