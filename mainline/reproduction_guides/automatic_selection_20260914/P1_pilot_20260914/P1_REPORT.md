- **BUSI（偏置比 5.42）**：胜率 56%、中位数 +0.027、灾难率 38% —— 这是**普遍性提升**，外加厚尾。
- **ISIC / Kvasir（偏置比 1.10 / 0.68）**：中位数为 0、胜率 <50%，平均增益全部来自右尾，是**尾部保险**。
- 收益集中在**高边距**目标，即"原始分数以很大优势选错样板"的地方——偏置以**过度自信**的形式出现。

## 修正后的结论

1. **校准有效性由偏置比门控，且动态范围很大**：偏置比 5.42 → +0.206；1.10 → +0.010（不显著）；
   0.68 → ≈0/−0.024。三点单调，且都可以用**免标注**的 `mu_A` 离散度预先算出。
2. **校准的边际价值随 k 递减，到 k=3 消失**（BUSI：+0.206 → +0.116 → +0.008 → 0）。
   原因是样板池只有 5 个，k=3 时已经装进大多数样板（BUSI 5 个中取 3 个）。
   所以"校准 vs 多留样板"是**可替代**的两种手段，不是独立的两个创新点。
3. **宽度（k）是另一个真实杠杆**：原始排序下 k=1→k=2 在三个数据集上一致提升 +0.037 ~ +0.160。
4. **深度会部分补偿坏样板**：BUSI 上校准增益从 b0 的 +0.206 降到全深度的 +0.079。
5. 因此论文主线应写成**两层**：
   - 底层框架：`Realized = Oracle − Gap`（E0），回答"瓶颈在覆盖、宽度/深度、还是验证"；
   - 具体机制：**样板分数偏置可免标注测量（偏置比），校准收益可预测，且与候选宽度可替代**。
   BUSI 是正例，ISIC/Kvasir 是阴性对照；正负结果都在，比只报正例更可信。
