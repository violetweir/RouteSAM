# 论文大纲：样板分数偏置、候选宽度与 Oracle/Gap 分解

**版本**：2026-09-14（基于 E0 + P1 + P1b + P2 的修正结论）
**定位**：少标注（1% 参考图）的 exemplar 式医学图像分割；冻结基础模型（SAM3），不训练大模型。

---

## 0. 标题候选与一句话贡献

标题候选：

- *Coverage, Breadth and Calibration: What Actually Drives 1%-Label Exemplar Segmentation*
- *Anchor Scores Are Not Comparable: A Measurable Bias, Its Predictable Cost, and What to Do Instead*
- *Ceilings and Gaps: A Decomposition of Label-Efficient Segmentation with Frozen Foundation Models*

**一句话贡献**：
> 我们把"只标 1%"的 exemplar 分割分解为**可测量的天花板（Oracle）与验证差距（Gap）**；
> 证明样板条件分数在参考图之间**不可比**、该偏置可**免标注**测量并用于预测校准收益；
> 并给出一个反直觉结论：**校准、候选宽度 k、路径深度 m 是三个互相替代的杠杆**，
> 校准是其中最弱、最受数据集限制的一个——**把预算投在覆盖与宽度/深度上，比把分数排得更准更有效**。

---

## 1. 引言要讲的三件事

1. **问题**：密集标注昂贵；1% 参考图预算下，现有做法把"选哪些图标""怎么迁移""输出怎么挑"混在一起，无法解释不同数据集上哪一步是瓶颈。
2. **观察**（本文的起点）：冻结基础模型的样板条件分数（TP）在参考图之间**不在同一把尺子上**——
   像打分宽松的老师，某些样板天生给谁打都高分。BUSI 上 98.5% 的目标都选了同一张样板，而它的平均 Dice 只有 0.51。
3. **结论**：把这个偏置修好有用（BUSI 全深度 Oracle 0.617→0.775，最终 0.567→0.752），
   **但它的价值由偏置大小门控，且可以被"多留一张样板"替代**。真正稳定的杠杆是候选集合的宽度/深度。

---

## 2. 方法：一条统一流程（ACV）

只有一条流程、两个由验证集选择的超参，三个数据集完全同一套代码。

```
[0] 冻结 SAM3；缓存 1008 特征（选图用）与 256 特征（传播用）
        │
[1] 覆盖选图（Coverage，仅用 train RGB，不看 GT）
        S = 0.5·clip(GGᵀ,0,1) + 0.5·clip(HHᵀ,0,1)      G=全局描述子, H=局部视觉词直方图(IDF 加权)
        F(A) = (1/N)Σᵢ max_{a∈A} S(i,a)                 贪心最大化（单调子模）
        K = round(0.01·N_train)                          Kvasir 8 / ISIC 21 / BUSI 5
        │
[2] 人工标注这 K 张  ← 全流程唯一人工环节
        │
[3] 分数校准（Calibration，免标注）
        μ_A = mean_{x∈train RGB} TP(A,x)
        centered(A,T) = TP(A,T) − μ_A
        │
[4] 候选生成（Breadth × Depth）
        每目标按 centered 保留 top-k 样板（k 由验证集选）
        每个样板沿 beam search（width 32）生成 b0–b6 共 7 条路径
        → 每图 7k 个候选 mask；路径内部仍用原始 TP 与相邻 patch_mean 余弦做 (瓶颈,均值) 字典序评分
        │
[5] 验证（Verification）
        候选特征（桥长、路径瓶颈/均值、SAM 置信度、返回一致性 q_cycle、候选间一致性/面积、校准特征）
        → Ridge，按图像分组 CV 在 validation 上选 alpha 并拟合
        → 冻结每个 test 目标的 route 选择，之后才读 test GT
        │
[6] 汇报两个数：Oracle(H) 与 realized，Gap = Oracle − realized
```

**超参**：`k ∈ {1,2,3,5}`、`alpha ∈ {1,10,100}`，**同一套 validation 分组 CV 协议**在三个数据集上各自选择。
**不变量**：任何方法（选图/校准/保留数/桥深/验证器）只能改变 Oracle 或 Gap 之一，因此消融语义干净。

## 3. 理论骨架（5 条）

| # | 陈述 | 性质 |
|---|---|---|
| P1 | `F(A)=(1/N)Σᵢ max_{a∈A}S(i,a)` 单调子模；基数约束下贪心 `F(Â)≥(1−1/e)F(A*)` | **可证**（facility location） |
| P2 | `H_k ⊆ H_{k+1}` ⇒ `Oracle_k ≤ Oracle_{k+1}`（保留更多样板只抬天花板） | **严格成立** |
| P3 | `Realized = Oracle(H) − Gap(H,V)`；验证器 V 只作用于 Gap，**不改变 Oracle** | **严格成立** |
| P4 | 若 `s(A,T)=q(A,T)+b_A+ξ` 且 `E_train[q(A,·)]` 与 A 近似无关，则减 `μ_A` 消去 `b_A`，排序无偏；校准收益随 `Var_A(μ_A)` 单调 | **假设 + 实证检验** |
| P5 | 校准、宽度 k、深度 m 都能扩大"有效证据"，三者**互相替代**：校准收益随 k 增大而衰减（`k→K` 时归零）；宽度增益随深度增大而衰减 | **实证规律** |

> P1 目前只有代理指标证据（贪心在 100 组随机中排 100 百分位），**缺下游 Dice 对照**；见 §8。

## 4. 实验协议

- **数据**：Kvasir-SEG（800/100/100）、ISIC2018（2075/259/260）、BUSI（517/64/66）。
- **预算**：`round(0.01·N_train)` = 8/21/5；**1% 仅指参考图标注预算**，验证集 GT 是额外监督。
- **提示**：参考图 GT tight box，无文本。canvas 256。
- **指标**：逐图 Dice/IoU，宏平均；无平滑项，分母为 0 记 1。
- **冻结顺序**：所有选择先冻结（写 SHA256），之后才读 test GT。
- **统计**：逐目标配对 delta + 10000 次 bootstrap 95% 区间。
- **偏置诊断（免标注）**：`bias_ratio = std_A(μ_A) / std_T(max_A s(A,T))`，`μ_A` 只由 train RGB 算出。

## 6. 可以主张的贡献（5 条）

1. **一个统一流程 ACV**：覆盖选图 + 免标注校准 + 宽度/深度候选 + 验证器，两个超参同一协议选择。
2. **一个可测量的偏置诊断与预测性规律**：样板条件分数不可比，偏置比免标注可算，且校准收益随它单调（0.68→≈0，1.10→+0.01，5.42→+0.21）。
3. **一个分解框架 + "三杠杆互相替代"结论**：`Realized = Oracle − Gap` 让改进可归因；校准、宽度 k、深度 m 都只是扩大有效证据，且互相替代——**校准是三者中最弱、最受偏置门控的一个**。
4. **正例与阴性对照并存的实证研究**：BUSI 为强正例，ISIC/Kvasir 为阴性对照，避免"只报有效数据集"。
5. **一个关于预算的实证发现**：单张标注的全深度天花板已达 0.9142（Kvasir test），标到 1% 的 8 张只再涨 +0.040 —— 1% 预算偏保守。

## 7. 必须写进 limitation

1. **校准不是普遍解药**：偏置比 ≈1 时不显著（ISIC），0.68 时无效（Kvasir）。
2. **ISIC2018 的全深度校准增益尚未测**。目前全深度证据是 BUSI（显著 +0.079）与 Kvasir（无效），b0 证据三点齐（1.10 不显著）。
3. **Router 使用 validation GT**；1% 只是参考图预算，不是全系统标注量。
4. **test 已被多轮诊断**，不是盲测；除非补一个从未看过的数据集。
5. **"贪心选图优于随机"目前只有代理指标证据**（历史随机 100 组只算了覆盖值，`No propagation performed`）。
6. **分数→质量相关只有 0.1~0.4**（BUSI 上 raw 仅 +0.14），这是该方法族的固有上限，也正是 Gap 的来源。
7. **BUSI 只有 64 张 validation**，其选参与统计区间偏宽。

## 9. 一句话总结（可直接用作 abstract 结尾）

> 在冻结基础模型的 1% 标注分割中，性能上限由**候选集合的宽度与深度**决定；
> 样板条件分数在参考图之间不可比，这一偏置**无需标注即可测量**并能预测校准的收益，
> 但校准是最弱的一个杠杆，与"多留样板""加深路径"**相互替代**——
> 因此把预算投在覆盖与宽度/深度上，比把分数排得更准更有效。
