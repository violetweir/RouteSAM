# 单学生 S：已确认的伪标签构造

状态：正式软标签已生成并核查，硬/软两个对照训练已启动。与 [single_student_training.md](single_student_training.md) 配套使用。

## 主方案

保持已接纳的 580 张无标注训练图及冻结的 TP Router。每图使用相同的 TP b0–b6 七张候选；本阶段不再调整图像准入规则或训练集身份。

1. 保留返回一致性 `q_return >= 0.95` 的候选，组成集合 C。质量文件中该分数对应 `q_cycle`。
2. 在 C 中由冻结 Router 选择最高分候选，得到主 mask M。它与既有 580 张首批清单中的主 mask 保持一致。
3. 对 C 内的二值候选 mask 做等权平均，得到共识图 P：`P = mean(M_k for k in C)`。不合格候选不参与平均。
4. 构造最终监督目标：

**`Y = 0.75 * M + 0.25 * P`**

0.75/0.25 是本轮固定的初始配方，不代表已经证明最优。共识图的数值表示候选前景投票比例，不是经过校准的正确概率。

## 单候选与形状约束

当只有一个合格候选时，P=M，Y=M，保持硬标签；不将该情况解释为多候选一致。

当 M=1 时，Y 位于 [0.75,1]；当 M=0 时，Y 位于 [0,0.25]。因此 `Y >= 0.5` 的二值结果仍等于 M。这一方案软化监督置信度，不直接修正主 mask 的二值边界。

| M | P | Y |
|---:|---:|---:|
| 1 | 1.0 | 1.00 |
| 1 | 0.6 | 0.90 |
| 1 | 0.2 | 0.80 |
| 0 | 0.8 | 0.20 |
| 0 | 0.4 | 0.10 |
| 0 | 0.0 | 0.00 |

## 与等权训练的对应关系

- 8 张 GT 图使用真实 0/1 标签。
- 580 张伪标签图使用上述 Y，训练时保留软值。
- 所有图像、所有像素的损失权重均为 1；不额外引入伪标签系数、质量权重、像素忽略或 ramp。
- 每张图计算 BCE + Soft Dice，再对 batch 中所有图像取平均。
- 0.75/0.25 是监督目标的混合比例，不是样本损失权重。
- 图像与标签的几何变换必须同步，软目标进入损失前不得再次阈值化。

训练集共 588 张，统一随机打乱、每轮完整遍历，batch size=12，训练 816 epoch，即 39,984 iter。

## 固定的对照设计

| 版本 | 580 张伪标签的目标 | 其他训练设置 |
|---|---|---|
| 硬标签对照 | Y=M | 相同 |
| 主方案：合格候选软共识 | Y=0.75M+0.25P | 相同 |

两版训练图像身份、GT、主 mask、初始化 seed、采样、增强、优化器、训练长度和验证方式应保持一致，只比较监督目标的变化。硬标签也是统一 BCE + Soft Dice 入口的 0/1 特例，不换成另一套训练损失。

## 实现时需核查

- 580 张图的合格集合均非空，主 mask 属于该集合。
- 共识只来自返回检查合格的 TP 候选，不依赖学生预测或目标图 GT。
- 全部 Y 均在 [0,1]，阈值化后与对应主 mask 一致。
- 若使用 uint16 PNG 保存软标签，解码必须除以 65535；GT 与硬 mask 解码为 0/1。不得将软标签按 uint8 或二值 mask 解码。
- 硬/软两个对照只改变监督目标文件，不改变训练身份和样本权重。

上述核查已通过；正式训练正在进行，最终结果尚未产生。执行记录见 [single_student_experiment.md](single_student_experiment.md)。


## 实验完成更新

硬、软两组均完成 816 epoch（39,984 iter），随后固定各自 validation-best 并评估完整 test。硬标签 validation/test Dice 为 0.819562/0.848592，软标签为 0.827330/0.851243。软标签 test 平均提高 0.002651，配对 95% 区间跨零，尚不能确认稳定提升。完整结果见 [single_student_experiment_results.md](single_student_experiment_results.md)。
