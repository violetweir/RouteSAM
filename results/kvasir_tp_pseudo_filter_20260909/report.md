# Kvasir：Router 用途与首批伪标签覆盖率诊断

日期：2026-09-09。仅检查已有 TP b0–b6 候选；未训练新模型、未评估 test、未替换原伪标签池。

## Router 的职责

独立 Router 是使用 validation 候选特征与其真实 Dice 拟合的标准化 Ridge 回归器。推理时只输入路线、传播、循环一致性等特征，为七个候选估计质量，选分数最高者；不会输入当前目标 GT。

- 纯 SAM3 test 基线：每张 test 图七选一，全部 100 张输出，Dice 0.885433。不施加训练伪标签的两个通过阈值。
- 训练伪标签：同一个冻结 Router 对全部 792 张图七选一，然后额外进行质量筛选。
- 学生+B7 的 test：B7 利用返回、多路线及 X3 一致性重新选七个 TP 候选，独立 Router 的 test 输出作为基线比较。它不是“先 Router 缩成一个候选，再由 B7 选择”。

“独立 Router”指 TP-only 专属候选选择器，不表示专门在 test 上训练 Router。

## 为什么第一批只有 448 张

七个 TP 候选两两平均 Dice 作为图像级 q_multi，Router 选中候选的反向循环 Dice 作为 q_return。必须同时满足 q_multi≥0.90、q_return≥0.95。

| 情况 | 训练图数 |
|---|---:|
| 两项都通过 | 448 |
| 仅多路线一致性不过关 | 76 |
| 仅返回一致性不过关 | 160 |
| 两项都不过关 | 108 |
| 总计 | 792 |

448/792=56.57%。其余图都有候选和 Router 选择结果，这个数是伪标签接受率，不是模型成功输出率。

初始 448 张训练 S2/S3；委员会再接纳 A=94、B=113，X3 共使用 655 张伪标签，即 82.70%的无标注训练图。137 张 C 档不进入 X3。

## 固定阈值下检查筛选顺序

现有顺序：七个候选中先选 Router 最高分，若该候选返回一致性不通过，则整张图不进初始池。

在仅返回一致性失败的 160 张图中，132 张有其他候选满足相同 q_return≥0.95。若先排除返回一致性不过关的候选，再用同一个 Router 排序，并维持原 q_multi≥0.90，则训练接受数从 448 变成 580。原 448 张的选中 mask 完全不变。

这 132 张中，原委员会已经接纳 73 张 A、42 张 B，共 115 张；仅 17 张原本位于 C。因此不能将 132 全部计作 X3 新增数据，也不能将 580 与原 A/B 直接相加而不去重。

## Validation 折外诊断

Router 按目标图做 5 折交叉验证，seed2026、ridge1，与已有 100 个 TP 折外选择逐图一致。这里评估的是伪标签筛选后的子集质量，不是完整 validation 或 test 分割成绩。

| 子集 | 张数 | 平均 Dice | 中位数 Dice | Dice<0.5 |
|---|---:|---:|---:|---:|
| 原规则接纳 | 51 | 0.942856 | 0.956322 | 0 |
| 调整顺序后接纳 | 71 | 0.913386 | 0.954573 | 3 |
| 其中新增子集 | 20 | 0.838237 | 0.944910 | 3 |

新增这 20 张原 Router 首选的平均 Dice 为 0.843000，改选返回阈值合格候选后为 0.838237，未呈现更好的平均质量。

此前报告中的 52/100 是用完整 validation 拟合 Router 后的筛选数；本诊断 51/100 来自折外 Router，统计口径不同。

## 对优化的影响

选择最高预期分割质量与达到伪标签使用要求是两个任务。相对排序不能保证绝对质量；返回一致性、多路线一致性也都不等于目标正确性。

不建议仅为提高通过数量，直接将 580 张作为同等可靠的硬伪标签替换初始池。高质量种子池与后续带权扩充池应区分。现有 448→655 的递进机制已经回收了多数本次发现的候选。

后续更有意义的对照是在保留单 TP 候选与 test 基线的前提下，检查剩余 137 张中哪些属于整图失效、哪些仅有局部不确定，并验证能否利用可靠像素进行低权重监督。需要先在 validation 上检查新筛选规则的覆盖率、平均质量及严重错误比例，再重建伪标签/委员会与学生流程；不能由 train 接受数量直接推断会提升最终 Dice。

本目录 `train_preview_manifest.jsonl` 仅是按固定阈值调整顺序得到的 580 张预览，没有被用于训练。结果保存在 `results.json`；逐图诊断保存在训练与验证 JSONL 中。
