## 结果解释

全部 1669 条去重路径及三组选择器评估已完成，未运行新 test。

1. B 的主要选择器 Dice 为 0.857937，相对原 TP 增加 0.006182（约 0.62 个百分点）。配对 bootstrap 95% 区间为 [-0.003197, 0.018292]，仍跨 0；五折中三折增加、两折下降。59 次替换产生 27 次提升、31 次下降、1 次持平，不能据此宣布稳定改进或更换正式基线。
2. 固定 TP 路径后，PC 备用 anchor 检索（C）的联合 Oracle 比 TP 备用检索（B）低 0.013367，描述性配对区间为 [-0.026774, -0.003024]。本轮证据更支持优先改善参考图选择，而非继续依赖原 PC Top-8 检索。
3. 固定 PC 备用 anchor 后，PC 路径（D）相对 TP 路径（C）增加 Oracle 0.005662，但区间 [-0.001024, 0.015415] 跨 0；主要选择器实际 Dice 反而下降 0.002408。PC 路径仍可能提供少数有价值候选，尚未形成可靠的实际收益。
4. B 的完整十四候选 Oracle 为 0.898534，主要选择器实际 Dice 为 0.857937。主要选择器只能访问冻结 TP 的一个输出加辅助七候选，这个受限池的 Oracle 为 0.893326，仍有 0.035389 的选择差距。完整池与受限池的上界不能混为同一个选择器的可达上界。
5. B 若直接使用联合 Router，Dice 降至 0.829984，说明候选池改善并不保证联合重排有效。继续保持 TP 独立输出作为默认结果更有依据，但当前替换策略仍有较多错误替换。

当前正式基线仍为 SAM3-base TP b0–b6 独立 Router，历史 test Dice 0.885433。本表的 0.851755 与 0.857937 都是 validation 折外成绩，不能与 test 数字直接当作升降比较。

建议下一轮冻结 B 的候选池，针对目标端质量证据与替换收益建模做单独对照；尤其应区分当前沿用的对象分数与逐帧 tracker 分数。新的质量字段也需独立验证，不能预设等价于 mask Dice。本轮不因挑到最高外层均值就自动运行 test。
