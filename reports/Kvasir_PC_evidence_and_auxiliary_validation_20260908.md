# Kvasir：PC 对应证据改进与替代辅助机制，第一阶段验证

日期：2026-09-08。结论：本轮完成对应证据和候选排序实验，尚无方案通过预设 test 启用标准；保留 TP 独立 Router。局部原型核验有小幅、尚不稳定的 Dice 改善；前景—背景对应图有较好的粗定位信号，但未转化成稳定的候选选择收益。

## 1. 本轮范围与保持项

- SAM3-base 冻结，原 800/100/100 数据划分、8 张训练标注与 792 张无标注身份保持。
- 无学生；不改 TP 原 anchor、路径、候选 mask 或 Router 特征输入。
- 新提取原 100 张 validation 图和 8 张训练支持图的 SAM3 trunk token，18×18，每 patch 1024 维。
- 评估 PC 自身时，使用原 PC b0–b6 七候选，改进对应质量证据并检查排序。
- 评估辅助作用时，默认结果为独立 TP Router，每图保留默认 TP mask 和七个原 PC mask；辅助证据可以来自 PC，也可以来自图像区域和边界。
- 本轮尚未重新生成 PC 路径或传播 mask，也未实现 SAM3 提示修正。它检验的是新证据是否值得进入下一阶段，不能写成完整 PC 路线已优化成功。

## 2. 对应与非 PC 证据

原型局部核验（PC-proto）：保留前景 prototype 到 target patch 的余弦相似度，增加候选内部均值、内部与邻近背景环的差值、内部标准差，以及原 Top-8 均值。局部区域由候选预测 mask 定义，不使用目标 GT。

前景—背景多 patch 对应（PC-FG/BG）：从训练支持 GT 得到前景 token 集 F 和背景集合 B。对 target patch j：

`c_j = mean Top-min(3,|F|) {cos(a,x_j): a∈F} − mean Top-3 {cos(b,x_j): b∈B}`

候选证据包括内部 c 均值、内部减背景环均值、内部正 c 占比，以及前景支持 patch 的最近匹配落入该候选的覆盖率。小支持病灶只取实际存在的前景 token，不补造 patch。

双向一致性（PC-mutual）：target patch 找最近 anchor patch，再从该 anchor patch 返回最近 target patch，以返回位置的网格距离构造 `exp(−distance²/2)` 权重；增加双向前景支持和对应覆盖证据。

非 PC 区域/边界对照：候选内外 RGB 均值差、Sobel 边界梯度、边界与背景环的梯度差、区域内外梯度，以及 mask 占包围框比例。它是简单图像证据对照，尚不代表所有非 PC 辅助方法。

辅助评估的两个候选使用同一个 TP 所选 anchor 作参照，避免直接比较两个不同 anchor 的对应分数。将默认 TP 的证据和候选相对默认的差值加入原 15 个增益特征；TP 原选路不变。PC 自身排序则使用每个候选自身的支持 anchor。

## 3. 验证协议

全部按目标图分组，禁止同一张图的不同候选分属训练与验证。

PC 自身：外层 5 折、内层 4 折；候选 scorer 的 Ridge 为 1 或 10，历史 scorer 固定 1。每个外层折内，通过内层验证选择证据类型和正则，再评估未参与选择的外层图像。

TP 辅助：外层 5 折、内层 4 折；构造门控训练样本的专家输出来自更内层 3 折交叉拟合。增益 Ridge 为 10/100，替换阈值为 0.02/0.05/0.10，允许精确保留 TP。每图七候选合计单位样本权重，避免将 7N 个候选误当 N 的七倍独立图像。

主要指标来自“内层选择证据类型后”的完整外层结果；各固定证据类型的消融仅作解释，不按其最高外层分数触发 test。

预先固定 test 条件：主要外层平均 Dice 增益≥0.003，配对 bootstrap 95% 区间下界>0，至少 3/5 折改善。原划分不变；validation 已在历史研究中反复使用，因此这里的嵌套验证不能消除跨研究轮次的复用效应。

## 4. PC 自身候选排序

以下均为原 100 张 validation 的外层结果，不是 test。

| 证据 | PC Dice | 相对原 PC |
|---|---:|---:|
| 原 PC Router | 0.817329 | — |
| 原型局部核验 | **0.822766** | +0.005436 |
| 前景—背景多 patch | 0.808145 | -0.009184 |
| 前景—背景 + 双向一致性 | 0.812606 | -0.004723 |
| 非 PC 区域/边界 | 0.811576 | -0.005754 |
| **内层选择证据类型，主要结果** | **0.807762** | **-0.009567** |

原型局部核验在 4/5 折改善，但增益区间为 [-0.002121, 0.017243]，跨 0。内层选择的方案在外层未获得整体收益，反映这组证据/学习器/数据规模下的选择不稳定；不能事后只挑最高消融列作为成功方案。

候选集合保持不变，所以这里没有提高 PC 候选 Oracle，也没有测试新路径生成。

## 5. TP 主分支 + 辅助证据

| 辅助方法 | Validation Dice | 相对 TP |
|---|---:|---:|
| 原 TP 独立 Router | **0.851755** | — |
| 旧统计特征增益重排序 | 0.851639 | -0.000116 |
| 原型局部核验 | **0.853798** | +0.002043 |
| 前景—背景多 patch | 0.851569 | -0.000186 |
| 前景—背景 + 双向一致性 | 0.850392 | -0.001364 |
| 非 PC 区域/边界 | 0.846641 | -0.005114 |
| **内层选择证据类型，主要结果** | **0.849145** | **-0.002611** |

原型局部核验的增益区间为 [-0.001216, 0.007499]，且平均增益低于 0.003。它的正收益较集中，不能作为稳定改进。

主要结果替换 22 张：11 张改善、10 张下降、1 张相同。正 Dice 差合计 0.288876，负差合计 -0.549944；少量较大的错误替换压过收益。该辅助候选集合的 Oracle 为 0.886340，仍存在潜力，但本轮证据和增益回归没有稳定利用它。

PC 自身和辅助两个主要结果都未通过标准，因此本轮没有读取 test 特征、生成 test 输出或报告新的 test Dice。原 TP test 0.885433 仍属于历史冻结基线。

## 6. 对应图诊断：是否包含定位信号

作为 GT 事后诊断，使用 OOF TP 所选 anchor，在 18×18 网格上比较 patch 分数区分前景与背景的逐图 AUC。目标 GT 仅在这里下采样用于统计，没有进入对应计算、选路或候选选择。100 张均同时含前景与背景 patch。

| 对应图 | 平均逐图 patch AUC |
|---|---:|
| 前景原型余弦图 | 0.834614 |
| **前景—背景多 patch 对应图** | **0.893630** |
| 双向前景支持图 | 0.720818 |
| 双向加权前景—背景图 | 0.745572 |

这个结果提示：在 TP 所选支持下，前景—背景对应图有比原型余弦更好的粗粒度定位信号，但当前将其压缩成候选特征、再回归整张 mask 的 Dice 增益，并未转化出稳定的分割收益。

AUC 只衡量 patch 排序，不证明阈值校准正确、边界准确或能改善最终 Dice；这里采用的 TP anchor 也不同于 PC 自身排序中的候选各自 anchor。因此不能据此宣称前景—背景 PC 全路线已优于原 PC。

双向约束在这项诊断中表现较差，可能会对跨实例、非一一对应的病灶纹理施加过强限制，但本轮还没有单独证明失败原因。

## 7. 下一阶段依据

优先保留前景—背景对应图作为待验证的区域提示来源，而不继续扩展当前线性重排序的权重搜索。下一阶段可在固定 TP anchor/路径条件下，将对应图中的可靠区域变为 SAM3 点或框提示，再生成修正候选，直接检验是否改善候选质量和最终 Dice。需要保留原候选，分别报告新生成候选的质量、扩展候选 Oracle 和实际选择结果。

18×18 对应图应提供区域级证据，不能直接宣称可精确修补像素边界；边界仍应由 SAM3 解码或其他经过验证的细化模块处理。

辅助方法保持开放。非 PC 区域/边界的这组简单特征没有成功，尚未覆盖多视图不确定性、区域提示一致性等其他方向。最终是否采用 PC 或其他机制，应由相同协议下的实际增益决定。

## 8. 数值、隔离与产物核验

两张 GPU 正被其他任务使用，本轮采用 CPU float32、4 线程提取 trunk token。严格加载同一 SAM3-base trunk 权重；针对仓库推理融合 MLP 强制转 bfloat16 导致 CPU dtype 不匹配的问题，仅在本进程替换为等价的 float32 Linear + GELU/ReLU，没有修改 SAM3 源文件。

新增 CPU 特征不宣称与历史 GPU bfloat16 位级相同。8 个 anchor prototype 与历史缓存的余弦相似度为 0.999862–0.999977；全部新证据使用同一个 CPU 编码路径作对照。历史 mask、Router 输入及其基线结果没有变化。

核验：108 份 token 均为原 validation 与 8 个 train supports，形状 324×1024，全部有限，最大单位范数误差 3.58e-7；85 组专家拟合/评估划分均不相交；原 PC、TP 和旧候选重排序的验证结果均复现。
