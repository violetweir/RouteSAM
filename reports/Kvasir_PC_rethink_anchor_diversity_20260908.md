# Kvasir：重新判断 PC 的作用与下一轮改进方案

日期：2026-09-08。本文属于诊断与实验设计，尚未执行下文的新传播实验。

## 1. 当前判断

目前不应继续把“PC 提供局部对应能力”当作已经成立的前提。现有结果更支持先检查另一个解释：PC 的主要作用可能是找到 TP 没有选中的参考图像（anchor），从而生成不同的传播结果。

优先级应调整为：**分离 anchor 检索与路径传播的贡献 → 在固定候选预算下验证有效多样性 → 再改善候选选择。** 暂停继续叠加空间项、框提示、点提示或联合权重。

这不是已经证明 PC 无效，也不是预先决定它必须成为辅助分支。保留什么机制，应由下面的对照决定。

## 2. 先统一分数口径

| 结果 | validation | test |
|---|---:|---:|
| TP b0–b6 独立 Router 实际 Dice | 0.851755（5 折 OOF） | 0.885433 |
| TP b0–b6 候选 Oracle Dice | 0.869544 | 0.907426 |
| TP+PC b0–b6 候选 Oracle Dice | 0.889432 | 0.921471 |

0.851755 是 validation 的折外预测结果；0.885433 是在完整 validation 上拟合 Router 后的 test 结果。两者不是同一批图像、同一训练规模下的前后改进。沿用原来的数据划分及 8 张有标注、792 张无标注训练图身份。

Oracle 使用目标 GT 逐图挑选最佳候选，只用于事后诊断。它不能作为可部署方法的实际性能，也不能用于推理时选择候选。

## 3. 新诊断：主要收益可能来自不同 anchor

在原版 validation 的 100 张图像上，逐图比较 TP 七个候选，以及 PC 七个候选使用的 anchor：

- 98/100 张图像的 TP 七个候选只涉及一个 anchor。
- 96/100 张图像的 PC 七个候选也只涉及一个 anchor。
- PC 在 36 张图像上提高联合 Oracle，其中 18 张的获胜 PC 候选使用了 TP 池中没有的 anchor。

采用嵌套候选池分解：先保留全部 TP，再加入与 TP 共享 anchor 的 PC，最后加入其余 PC。

| validation 候选池 | Oracle Dice | 相对上一行增加 |
|---|---:|---:|
| 原 TP 七候选 | 0.869544 | — |
| TP + 共享 anchor 的 PC 候选 | 0.870881 | +0.001337 |
| TP + 全部 PC 候选 | 0.889432 | +0.018551 |

增加不同 anchor 候选的条件增量，占全部 PC Oracle 增量约 **93.28%**。这是增量占比，不是图像占比。

这是观察性诊断，不是因果消融：新增候选同时改变了 anchor、路径和候选数量。但它足以说明，必须先检验“换了有用参考图”的解释，不能直接把 Oracle 增益归功于局部对应机制。

另外，这 18 个有收益的新 anchor 在 TP 原始 anchor–target 得分中的排名为：第 2 名 6 个，第 3 名 1 个，第 4 名 4 个，第 5 名 3 个，第 6 名 1 个，第 7 名 3 个。按收益加权，TP top-2 覆盖约 57.44%，top-3 约 63.37%。因此 TP 第二参考图是必须做的对照，但不能预设它能覆盖全部 PC 收益。

数据见本目录 `anchor_diversity_diagnostic.json`、`alternative_anchor_rank.json`。远端还有逐图 JSONL。

## 4. 原始 TP 与 PC 并非两套独立表征

核查 `scripts/stage1_feature_knn_routes.py`：两者都从相同的 anchor 前景 prototype p、相同的 target patch 特征 x_j，得到 s_j = pᵀx_j。

- TP：对 s 做 softmax(10s)，加权汇聚 target 特征，再归一化后与 p 比较。
- PC：对同一组 s 取 Top-8 平均。

因此原 PC 更准确地说是“前景 prototype 到 target patch 的 Top-K 打分”。它尚不是完整的前景 token 与 target token 之间的局部匹配系统。“TP 负责区域、PC 负责局部结构”的表述，目前缺少机制与消融证据。

后续的 FG/BG、mutual correspondence 证据实验主要改变候选质量特征，没有完成固定其他条件下的 anchor 检索与传播路径消融；这些负结果也不能直接否定真实局部匹配在检索阶段的价值。

## 5. 下一轮按顺序执行的实验

### 第一步：直接传播矩阵，检查相似度能否预测可迁移性

固定 b0，不使用中间桥接图。让原来的 8 个有标注 anchor 分别直接传播到 100 张 validation 图像，最多形成 800 个结果。仅复用配置、输入及输出能核实一致的旧结果。

保持 SAM3-base、原图像预处理、256 输出画布和原生内部 1008 分辨率一致；不得把之前内部 256 的预实验混入主结果。

逐图得到 8 个 anchor 的实际传播质量，然后事后检查：TP/PC 得分的排序与传播 Dice 的关系、top-1/top-2 检索的收益、不同 anchor 的错误重合程度，以及是否存在跨图像总是较优的 anchor。

这一步回答“参考图相似是否意味着适合传播”。全 8 anchor Oracle 是诊断上界，不得当作相同候选预算下的提升。

### 第二步：固定十四候选预算，拆开检索与路径

每组完整保留原 TP b0–b6 的七个候选，另加七个候选；辅助组固定一个 anchor，遍历 b0–b6。检索排除主分支 b0 使用的 anchor，避免复制主参考图。

| 组别 | 辅助 anchor 选择 | 辅助传播路径打分 | 主要回答的问题 |
|---|---|---|---|
| B：TP 多参考对照 | TP 得分最高的另一 anchor | TP | 仅增加参考图多样性有多大价值？ |
| C：PC 检索辅助 | PC 得分最高的另一 anchor | TP | PC 的 anchor 检索是否优于 TP 的备选检索？ |
| D：PC 检索与路径 | 与 C 完全相同的 anchor | PC | 固定 anchor 后，PC 路径机制是否仍有额外价值？ |

保留原 TP 七候选作为基线；历史 TP+PC 十四候选作为参考，其 anchor 约束与 C/D 不完全相同，不能冒充干净的机制对照。

固定候选数量、bridge 数量、beam 搜索设置、数据和模型。B/C 的主要差异是辅助 anchor 选择；C/D 的主要差异是路径打分。先看候选质量与错误互补性，再用相同选择协议比较实际 Dice。

### 第三步：根据对照结果决定保留的机制

- 若 B 已覆盖主要收益：优先采用多参考传播。不要为了叙事硬保留 PC 名称。
- 若 C 稳定优于 B：PC 的价值在辅助参考检索。下一步改善对“传播是否有效”的预测，而非直接把热图变成最终区域。
- 若 D 稳定优于 C：固定参考图后的 PC 路径确有贡献，再针对路径评分做局部匹配、FG/BG 或覆盖约束消融。
- 若三组仅增加 Oracle、实际 Dice 都不升：先冻结候选生成，明确瓶颈在质量判断；不继续扩大候选池。

若后续需要检验真正的局部匹配，只先改一个机制：用多个 anchor 前景 token 对 target 区域的匹配覆盖率替代单 prototype Top-8，并在固定 anchor、固定候选预算下对照。背景对比和空间结构分别加，避免一次改变所有因素而无法解释收益。

## 6. Oracle 下降与实际 Dice 下降应分别处理

在相同图像、GT 和指标实现下，只要完整保留 TP 原候选，增加辅助候选后的 Oracle 就不可能低于 TP Oracle。这应作为结果完整性检查。如果下降，先检查候选被替换或删减、数据对齐以及评估口径。

但新的 PC 候选集可能不如旧 PC 候选集，因此新联合 Oracle 仍可能低于历史联合 Oracle。必须同时报告 TP、辅助独立、联合三个池，解释到底损失了什么。

实际 Dice 不具备上述单调性。新增候选会给 Router 更多犯错机会。旧联合 Router 还会改变 TP 内部的选择，所以应冻结 TP 独立 Router 的输出作为默认结果，让辅助模块只承担“是否有充分证据替换它”的任务。

这类保守替换之前已经试过，尚未取得稳定收益；它是隔离问题的结构，不是保证提升的解决方案。新的证据应优先来自跨参考图稳定性及误差差异，而非继续添加同源 Top-K 统计。

评估同时记录：实际平均 Dice、相对冻结 TP 的逐图增减、严重下降尾部、替换次数与获益比例、配对置信区间。不同参考图的一致性可能有价值，但两条分支都可能一起错，不能直接当作正确性。

## 7. 为什么暂停继续做框或点提示

原生内部 1008 的 validation 实验中，FG/BG 框直接预测 Dice 为 0.553532；通过 TP 一致性保护后为 0.848991，仍低于 TP 的 0.851755。框覆盖略增，但平均面积约为 TP 框的 1.79 倍，混入更多背景。

此外，原方法是有参考帧记忆的传播；新框实验是目标单图几何提示解码，不是只改了一个 correspondence score。SAM3 官方说明区分了图像检测器与基于记忆的视频跟踪器，因此不能仅从这次失败推断特征完全不可用。[SAM3 官方论文说明](https://ai.meta.com/research/publications/sam-3-segment-anything-with-concepts/)

如果以后再做细化，应保持实例跟踪/参考记忆的推理接口，并加入完全同接口的 TP-only 对照。直接从框换成点，也不足以构成方法贡献：参考图引导的定位先验、提示与后续细化已有相关工作。[PerSAM](https://arxiv.org/abs/2305.03048)

## 8. 实验与论文表述约束

推理只能使用原有训练支持样本及允许的图像特征，目标 GT 仅用于评估。保持原数据及有无标注划分，候选行必须按目标图像分组做折外评估，不能让同一图像的不同候选跨越训练和验证。

先完成上述 validation 对照并锁定方法及超参数，再按固定协议评估 test。test 已被多次查看，后续不能把它表述为从未参与开发判断的全新留出集。

目前最有依据的研究问题是：**怎样找到可互补的参考图，并判断其传播结果是否值得替换稳定主结果？** “区域主分支 + 局部辅助分支”只能作为待验证假设。最终叙事应随检索、路径和选择三个层面的证据确定。
