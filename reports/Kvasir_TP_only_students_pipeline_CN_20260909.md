# Kvasir：TP-only 伪标签 → S2/S3 → 委员会 → X3 → B7 的实际流程

本文依据 `work/kvasir_tp_student_mainline_20260907/code` 中实际运行的脚本、配置及训练摘要整理。所有候选范围按本次命令参数为 b0–b6，共七个 TP 候选。

## 1. 固定的数据、教师与学生

- 数据沿用原 train/validation/test = 800/100/100。训练集中人工标注 8 张、无标注 792 张，身份不变。
- 教师为冻结的 SAM3-base，使用 Target Pooling 检索及 b0–b6 传播。b0 表示 anchor 直接到目标，b1–b6 分别加入 1–6 张训练桥接图。
- SAM3 特征检索输入为 256；传播图像先缩放到 256×256 画布，视频模型内部仍使用原生 1008 分辨率。
- S2、S3、X3 都实例化 SC-SAM 项目中的 `SamUnet`。检查实际类实现，它包含一个 U-Net，输入 RGB 图像，输出背景/息肉两类预测，不含 SAM3 编码器。
- S2、S3 各自独立初始化训练；X3 使用扩充的数据另行初始化训练。本轮没有加载 S2/S3 权重作为 X3 的初始化。
- 训练标签来自 8 张人工 GT 和选定伪标签；validation 用于 Router 拟合与学生 checkpoint 选择。未用 test 选择本轮 checkpoint。

整体关系：

```text
8 张标注 anchor + 792 张无标注训练图
                  ↓ 冻结 SAM3-base，TP b0–b6
           每张图 7 个候选，共 5544 个
                  ↓ 独立 Router + 质量筛选
              第一批 448 张伪标签
             ↙                    ↘
      S2：选中硬标签          S3：七候选共识软标签
             ↘                    ↙
         两模型各取 best/final，共 4 个 checkpoint
                  ↓ 审核剩余 344 张图
             A 94 / B 113 / C 137
                  ↓ 原 448 + A + B
             655 张伪标签 + 8 张 GT
                  ↓ 重新训练 X3
               validation 选 best
                  ↓ 为 TP 七候选提供一致性评分
                 B7 选一个 SAM3 mask
```

## 2. 第一批 448 张伪标签怎么得到

先复用 792×7=5544 条同配置 TP 传播结果，再用冻结的独立 Router，为每张图选出一个二值 mask。

接着计算两个无目标 GT 的质量指标：

1. 图像级多路线一致性 `q_multi`：对七个候选两两计算 Dice，再对 21 对取平均。七条路径分割越一致，值越高。
2. 返回一致性 `q_return`：将选中的目标预测 mask 注入一个新的跟踪状态，沿相同图像序列反向传播回 anchor，再与该 anchor 的人工 GT 计算 Dice。该步骤使用已知 anchor GT，不使用无标注目标的 GT。

同时满足 `q_multi ≥ 0.90` 和 `q_return ≥ 0.95` 才进入第一批伪标签池，得到 **448/792 张**，剩余 **344 张**进入后续委员会审核。

每张保留图像还获得一个图像级训练权重：将池内 `q_multi` 做 min–max 归一化，再截断到 [0.2,1]。更一致的样本在伪标签损失中占更高权重。

产物：`pseudo_manifest_original.jsonl`。

## 3. S2：学习 Router 选出的硬伪标签

训练样本为 8 张人工 GT 图像和 448 张第一批伪标签图像。每张伪标签就是 Router 选中的那个 SAM3 二值 mask。

每个 batch 为 12 张，其中 6 张来自人工标注池，6 张来自伪标签池；8 张标注图通过反复采样参加训练。标注样本用弱增强，伪标签样本用强增强，图像与标签同步变换。

- 人工标注损失：交叉熵 + Dice loss。
- 伪标签损失：每图交叉熵 + Dice loss，再乘前述图像质量权重。
- 总损失：人工标注损失 + `0.5 × ramp × 伪标签损失`。
- `ramp` 在前 2000 次迭代由 0 线性增长到 1，减少训练初期伪标签的影响。

S2 使用 SGD，初始学习率 0.01，momentum 0.9，weight decay 1e-4；学习率随训练线性下降。训练 40000 次，每 200 次用普通 validation Dice 验证，seed=2026。

保存两个 checkpoint：validation-best 为第 **32800** 次；final 为第 **40000** 次。训练内 best validation Dice 为 **0.816123**。S2 此阶段未单独跑 test。

## 4. S3：学习七个 TP 候选的共识软标签

S3 使用与 S2 完全相同的 8+448 张图，但 448 张图的监督目标不同。

对某张图，把七个 SAM3 二值候选逐像素取平均：

`软标签 P(x) = [M0(x)+…+M6(x)] / 7`

例如某像素在七个候选中有五次被认为是息肉，该像素的软标签为 5/7，而不是直接设为 1。

再计算七个候选在该像素的方差，并设置：

`像素权重 W(x) = max(0.1, exp(-4 × 方差(x)))`

候选一致的像素监督更强；分歧较大的区域监督减弱。S3 伪标签损失为像素加权 BCE + 像素加权软 Dice，并继续乘图像级质量权重。人工 GT 损失、6+6 batch、0.5 全局伪标签系数、2000 次 ramp、优化器及总迭代数均与 S2 一致。

S3 保存的 validation-best 是第 **29800** 次，final 是第 **40000** 次；训练内 best validation Dice 为 **0.814231**。S3 此阶段未单独跑 test。

本轮训练前修复了 16 位 PNG 的读取：软标签和像素权重按 uint16/65535 归一化，避免被普通灰度转换饱和为 0/255。

产物：`S3_consensus/pseudo_consensus.jsonl`、共识概率图和像素权重图。

## 5. 四成员委员会：重新审核剩余 344 张图

委员会由以下四份 checkpoint 组成：S2-best、S2-final、S3-best、S3-final。这是两次学生训练产生的四个模型快照。

四个成员分别对训练图像输出前景概率图和二值 mask。审核对象为没有进入原 448 张池的剩余 **344 张**图像。

对每张图的每个 TP 候选 M_j，计算：

- 候选级 `q_multi,j`：该候选与其余六个 TP 候选的平均 Dice。这里与第一轮“21 对平均”的图像级定义不同。
- `q_model_mean,j`：该候选与四个学生二值预测的 Dice 均值。
- `q_model_min,j`：上述四个 Dice 的最小值。
- `q_model_var,j`：上述四个 Dice 的方差。

委员会候选分数为：

`q_route,j = 0.20 × q_multi,j + 0.80 × q_model_mean,j`

每张图先按此分数选一个 TP 候选，再进行 A/B/C 分级。这一步以学生与候选的一致性为主要依据，未使用剩余目标的 GT。

| 条件 | Tier A | Tier B（未进入 A 才判断） |
|---|---:|---:|
| 候选多路线一致性 | ≥0.90 | ≥0.75 |
| 四学生一致性均值 | ≥0.90 | ≥0.75 |
| 四学生一致性最小值 | ≥0.80 | ≥0.60 |
| 四学生一致性方差 | ≤0.01 | ≤0.03 |
| 委员会候选分数 | ≥0.88 | 无额外条件 |
| 非空与面积检查 | SAM3 非空，至少两名学生非空，面积处于原伪标签池 1%–99% 分位范围 | 代码未额外施加这组条件 |

其余为 Tier C。本次得到 **A=94、B=113、C=137**。C 不进入 X3 训练。

原伪标签池面积分位范围约为图像面积的 **1.62%–28.48%**。这些一致性阈值与区域面积规则是固定流程规则，并不保证伪标签必然正确。

## 6. 给新增 A/B 样本制作训练标签与权重

设委员会选中的 SAM3 二值 mask 为 M，四个学生前景概率图的均值为 S，则新增软标签为：

`P_new(x) = 0.75 × M(x) + 0.25 × S(x)`

这保留 SAM3 的主要区域判断，并让学生调整软监督强度。由于 SAM3 二值标签占 75%，将 P_new 以 0.5 二值化时，区域与选中的 SAM3 mask 相同；融合的作用体现在软标签数值。

此外，计算七条 TP 候选的逐像素方差 V_route、四个学生概率图的方差 V_student，以及 SAM3 与学生平均概率的分歧：

`W_final = clip(exp(-5V_route) × exp(-5V_student) × (1-|M-S|), 0.05, 1)`

TP 路径、学生之间以及 SAM3/学生之间越一致，像素权重越高。

新增图像级权重也按质量区分：A 为 `clip(0.5q_multi+0.5q_model_mean,0.3,1)`；B 为 `clip(0.25q_multi+0.75q_model_mean,0,1)`。

在 X3 中实际使用时，A 的像素权重统一为 1；B 将 W_final 离散为：≥0.70 权重 1，0.30–0.70 权重 0.25，<0.30 权重 0。即 B 中不可靠的像素会被弱化或忽略。

产物：`audit/tier_A.jsonl`、`tier_B.jsonl`、软标签图与像素权重图。

## 7. X3：用扩充后的伪标签池重新训练学生

X3 使用：原始 **448 张硬伪标签 + 94 张 A + 113 张 B = 655 张伪标签**，再加原来的 **8 张 GT**，共 663 个不同训练样本。

每个 batch 是 12 张：3 张 GT、3 张原始伪标签、6 张新增 A/B 样本。新增池合计 207 张；6 张并不固定分成 3 张 A 和 3 张 B。

- GT 与原始 448 张：使用硬标签交叉熵 + Dice。
- A/B：使用前述融合软标签，计算带像素与图像权重的 BCE + 软 Dice。
- 原始伪标签、A、B 的组别系数分别为 1.0、0.75、0.50。

总损失为：

`L = L_GT + 0.5 × ramp × (L_original + 0.75L_A + 0.50L_B)`

X3 同样训练 40000 次、每 200 次验证、前 2000 次逐步增加伪标签影响。它由同一 U-Net 结构重新初始化，不从 S2/S3 checkpoint 继续训练。

虽然底层训练脚本的某些历史字段仍写着 final/diagnostic，实际主线在完成训练后明确使用普通 validation Dice 最高的 `student_best.pth`，并在 test 前记录权重哈希。此次选中第 **24600** 次，训练内 best validation Dice 为 **0.821969**。

X3 对单张目标图可以直接输出自己的 mask，其 test Dice 为 **0.867161**。它还作为下一步 B7 的候选评价参考。

## 8. B7：让 X3 帮助挑选最终 SAM3 mask

对 validation/test 的每张目标图，仍使用原来的七个 SAM3 TP 候选，不增加 PC、备用 anchor 或新的 SAM3 mask。

冻结 X3-best，对目标图得到学生二值 mask S。对每个 SAM3 候选 M_j，计算：

1. `q_return,j`：该候选反向传播回 anchor，与 anchor GT 的 Dice。
2. `q_multi,j`：该候选与其余六个 TP 候选的平均 Dice。
3. `q_model,j`：该候选与 X3 二值 mask 的 Dice。

B7 分数为：

`Score_j = (q_return,j × q_multi,j² × q_model,j²)^(1/5)`

代码计算前将各项下限截为 1e-6。它是返回一致性、多路线一致性与学生一致性的加权几何平均，权重比例为 1:2:2。

取最高分对应的 SAM3 mask 作为最终输出。相同分数时依次用 q_multi、q_return、route_id 打破平局。B7 是固定候选选择规则，不是新增训练的网络；其 q_model 是两个预测 mask 的一致性，不是目标 GT Dice，也不是 SAM3 输出的预测 IoU。

此时的最终选路依据是 B7 公式，原独立 Router 已用于前面构建原始伪标签池。最终输出完整复制某个 SAM3 候选，不对七个候选做像素融合，也不把 X3 的 mask 替换为最终输出。

所有 100 张 test 图都输出结果，不通过置信度筛掉困难图。

## 9. 三种最终结果应分别报告

| 方法 | 最终 mask 来源 | Test Dice | Test IoU |
|---|---|---:|---:|
| SAM3 TP + 独立 Router | Router 选中的 TP 候选 | 0.885433 | 0.828274 |
| X3 单图 | X3 直接预测 | 0.867161 | 0.786951 |
| X3 + TP-only B7 | B7 选中的 TP 候选 | 0.892639 | 0.834468 |

B7 候选 Oracle 为 0.907426，仅供事后诊断。B7 相对独立 Router 的 test 平均差值为 +0.007207，配对 bootstrap 95% 区间 [-0.005002,+0.025372]，尚不足以宣布稳定提升。

本轮没有微调 SAM3。相对旧双路线学生流程，本轮同时更换为 TP-only 伪标签池并修复了 uint16 概率读取，因此旧新学生成绩的差异不能全部归因于路线变化。
