# Kvasir：候选上限下降与 B7 选择损失诊断

日期：2026-09-08。原数据划分、8 张训练标注、792 张无标注身份保持不变。SAM3-base、256 分辨率、b0–b6；学生均为此前按 validation Dice 冻结的 X3-best。本轮复用 mask 和学生预测，未重新训练学生或 SAM3。

## 用户澄清后的首要问题：无学生 SAM3 + Router 的退化

前文的学生 B7 对照不能替代无学生前端的验收。用户强调的主要问题是：TP 独立 Router 的 test Dice 为 0.885433，而加入 PC 后的联合 Router 为 0.874083，下降 0.011350。对应 Oracle 从 0.907426 升到 0.921471，选择损失从 0.021994 扩大到 0.047388。

再次按原始 `final_masks_no_student/b0_b6/*/per_target_metrics.jsonl` 逐图分解：

| 联合 Router 的选择 | 图数 | 相对 TP 独立结果改善/相同/下降 | 对全100图平均 Dice 差的贡献 |
|---|---:|---|---:|
| 选择 PC | 22 | 9 / 0 / 13 | -0.007930 |
| 仍选择 TP | 78 | 16 / 48 / 14 | -0.003419 |

仍选择 TP 的 78 张中，有 30 张换了 TP 路线。联合 Router 使用重新拟合的共享评分器，它同时改变了跨路线选择和 TP 内部排序；增加 PC 候选本身并不改变已有 TP mask，但采用联合评分后实际输出会退化。

若仅在“联合 Router 仍选 TP”的图上恢复独立 TP 输出，保持其 22 次 PC 替换不变，按保存结果计算的事后诊断 Dice 也仅为 0.877502，仍低于原 TP。这说明仅冻结 TP 内部排序尚不足以解决错误 PC 替换。

据此修正优先级：无学生主线继续使用 TP b0–b6 独立 Router；PC 保留为研究候选库，不凭 Oracle 较高就接入正式输出或伪标签选择。第5节的双路线 B7 配置仅是学生阶段已完成对照，不是已证明前端退化解决后的新默认主线。

之前不含学生的独立专家增益门控、全PC候选重排序均未通过分组验证；本轮含学生评分器也未通过。下一项前端实验需要新增 mask 本身的图像证据，例如候选内部与邻近背景的 SAM3 特征对比、边界与图像结构的一致性，而非重复相同统计特征的阈值搜索。任何可触发 PC 替换的规则都没有逐图不退化保证；启用依据必须是 validation 上对完整 TP+PC 系统的稳定收益，不能使用 test GT 或 Oracle 挑选。

## 1. 固定 B7 公式的 2×2 对照

评分为 `q_return^0.2 × q_multi^0.4 × q_model^0.4`，各项下限为 1e-6。q_multi 是候选与其余候选的平均 Dice，q_model 是候选与学生二值预测的 Dice。先选 mask，再读 GT 评估。所有对照事先固定，没有按 test 选择权重。

| 学生 | 最终候选池 | Validation Dice | Test Dice | Test Oracle | Test Oracle − Dice |
|---|---|---:|---:|---:|---:|
| 旧 X3 | TP，7 个 | 0.853357 | 0.888857 | 0.907426 | 0.018569 |
| 新 X3 | TP，7 个 | 0.839690 | 0.892639 | 0.907426 | 0.014787 |
| 旧 X3 | TP+PC，14 个 | 0.833866 | 0.895432 | 0.921471 | 0.026039 |
| 新 X3 | TP+PC，14 个 | 0.840023 | **0.899542** | **0.921471** | **0.021928** |

最后一组 Test IoU 为 0.838703。两组历史 test B7 Dice 均精确复现。validation/test 各 700 个 TP mask 与新版保存的 TP mask 逐像素相同，q_cycle 也全部一致。

结论：

1. 固定 TP 候选池，新 X3 相对旧 X3 的 test B7 Dice 增加 0.003782；固定双路线候选池，增加 0.004110。因而本次 test 上并非新学生完全没有收益。validation 在 TP 池上则出现反向变化，不应宣称新学生普遍优于旧学生。
2. 删除 PC 缩小了候选集合，使 test Oracle 降低 0.014044。它是候选损失，不是学生预测或显示精度问题。复用原 PC 候选即可恢复此处的 Oracle，无需重新生成图片。
3. 新 X3 配双路线比新 X3 配 TP 的 test Dice 增加 0.006903，但 95% 配对 bootstrap 区间为 [-0.001288, 0.019120]。相对旧双路线增加 0.004110，区间为 [-0.001007, 0.010731]。两者均跨 0，当前是观察到的提升，不能宣称稳定显著胜出。
4. 新 X3 双路线 validation 相对新 TP 仅增加 0.000333。故本轮先保存为固定对照，不凭 test 更高替换已冻结基线。

## 2. 将总问题拆成候选与选择两部分

对第 i 张图，候选集合为 C_i，实际选中的 mask 为 m_i：

`Oracle = mean_i max_{m in C_i} Dice(m, GT_i)`

`选择损失 = mean_i [max_{m in C_i} Dice(m, GT_i) − Dice(m_i, GT_i)]`

Oracle 仅供 GT 事后诊断，部署时不能访问它。保持原候选并添加 PC，Oracle 在数学上不可能降低，但实际评分选择可能变差。缩小候选池会同时压低 Oracle 和选择损失，因此不能仅用更小的 gap 证明选择器更好。

Test 中 39 张图可从 PC 获得严格高于 TP 的 Oracle；其中收益最大的 10 张贡献了 90.13% 的候选增益。新 X3 双路线的 13 张图有超过 0.05 的选择损失，损失最大的 10 张贡献了总 gap 的 61.02%。因此应优先检查大幅漏选好 mask 的情形，而非单纯追求每张图都精确命中 Oracle。

Validation 的对应统计为：36 张可受益于 PC；新 X3 双路线有 18 张选择损失超过 0.05，最差 10 张贡献总 gap 的 73.15%。后续开发只用 validation 的这些案例，test 案例仅保留事后统计。

## 3. 已完成的评分改法：仅 validation

三种预先指定的简单改法：

- Soft model：把与学生二值 mask 的 Dice 替换为与正确解码的 uint16 学生概率图的 soft Dice。
- No multi：去掉共识项，保留 `q_return^(1/3) × q_model^(2/3)`。
- Cluster multi：按 mask Dice≥0.95、route-id 顺序贪心聚类；候选与各簇成员求平均后，再对簇求平均，避免重复候选按数量投票。候选自身排除，全部候选仍可被选择。

| 评分方法 | TP 池 Validation Dice | 双路线池 Validation Dice |
|---|---:|---:|
| 原 B7 | 0.839690 | 0.840023 |
| Soft model | 0.839627 | 0.840146 |
| No multi | **0.851953** | **0.845010** |
| Cluster multi | 0.840832 | 0.831612 |

去掉共识在 TP 池上提高 0.012263，但配对区间为 [-0.000005, 0.030549]，仍跨 0；双路线相对其原 B7 提高约 0.004986，也没有充分证据支持直接替换。

这支持继续检查共识项是否把“多个相似错误结果”当作高质量，但不证明共识项总是有害。软概率改法几乎不改变结果；本轮聚类规则也没有解决双路线选择问题。上述改法均未运行 test。

## 4. 已完成的学生信息增益评分器：条件交叉验证

与之前无学生信息的增益门控不同，本轮加入新 X3 的二值/软 Dice、前景和背景概率、候选边界处学生不确定性、面积偏差，以及 TP/PC 分别的共识、回传质量、SAM 分数和连通分量信息。使用候选相对 TP-B7 默认结果的特征差，预测候选 Dice 增益；保留全部 14 个候选，预测收益不足时回退默认结果。

采用按图像分组的 5 折外层 / 4 折内层验证，Ridge alpha∈{10,100}，切换阈值∈{0,0.02,0.05}，内层也允许始终回退。每张图的所有候选必须同折，不按候选行随机拆分。

- TP-B7 默认 Validation Dice：0.839690。
- 条件 OOF 增益评分器：0.844751，增加 0.005062。
- 95% 配对 bootstrap 区间：[-0.018595, 0.029897]。
- 35 张改善、46 张相同、19 张下降；5 折中 3 折平均改善。
- 未通过事先规定的“平均增加≥0.003、区间下界>0、至少3折改善”联合标准，因此未运行 test。

这里的交叉验证只隔离新评分器的拟合。冻结 X3 的 checkpoint 选择及上游伪标签 Router 已用过完整 validation，因此不能称为完整流程的独立 OOF 结果。区间也不包含重新训练学生、多次选择模型等不确定性。

## 5. 下一步的具体顺序

第一，保持 TP-only 伪标签和学生训练版本，恢复 TP+PC 14 个最终候选。它保留当前 TP 的训练收益并恢复已有候选上限。本轮已完成这个固定对照并导出 mask；无需立即重训 S2/S3/X3。

第二，优先改进“学生能否判断候选质量”，而不是继续扩大简单权重搜索。可在固定新 X3 上做 validation 的翻转 TTA，利用不同视图预测的分歧估计局部不确定性；将学生可靠区域和分歧区域的候选一致性分开计算，并检查边界偏差。这样提供当前单次二值 Dice 没有的信息。TTA 分歧只是待验证信号，不预设它会提高 Dice。

第三，给 q_multi 降权或回退必须由 validation 的稳定收益支持；不可因本轮 No multi 的均值更高就直接删除。已有线性增益评分器也尚未通过标准，暂不升级为正式选择器。

第四，下次学生训练应在保存多个 checkpoint 的基础上，对照“按单图 validation Dice 选 checkpoint”和“按固定候选池的 B7 validation Dice 选 checkpoint”。下游需要的是候选排序能力，单图分割最好不必然对应最佳排序；checkpoint 规则需提前固定，不能按 test 选。

若新增信息仍无法带来稳定的 validation 增益，再考虑专门的候选质量/排序训练和更严格的完整流程交叉验证。当前 100 张 validation 上多轮搜索已有复用效应，不能用同一批数据的越来越高拟合分数代替泛化证据。
