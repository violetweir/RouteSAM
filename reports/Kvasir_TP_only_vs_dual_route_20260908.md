# Kvasir：旧双路线与新 TP-only 学生主线对比

比较日期：2026-09-08。比较对象均为未微调SAM3-base、SAM3 trunk@256构路、256传播、b0–b6、同100张test、原8张人工标注。X3均使用按validation选择的best checkpoint。

旧版本：`work/rerun_c0_256_sam3knn_s256_base`。

新版本：`work/kvasir_tp_student_mainline_20260907`。

## Test 性能

为对齐口径，X3单图和B7均读取两版已保存的预测mask，在同一批GT上以256×256、NEAREST resize重新计算逐图Dice/IoU后取平均。没有重新训练模型或改变任何选择结果。

| 指标 | 旧 TP+PC 双路线 | 新 TP-only | 新版变化 |
|---|---:|---:|---:|
| 无学生Router Dice | 0.874083 | **0.885433** | +1.135个百分点 |
| X3单图Dice（统一导出mask口径） | 0.854101 | **0.867161** | +1.306个百分点 |
| X3单图IoU（统一导出mask口径） | 0.771470 | **0.786951** | +1.548个百分点 |
| X3-best + B7 Dice | **0.895432** | 0.892639 | -0.279个百分点 |
| X3-best + B7 IoU | 0.832311 | **0.834468** | +0.216个百分点 |
| 候选Oracle Dice（仅GT事后分析） | **0.921471** | 0.907426 | -1.404个百分点 |
| Oracle减B7 Dice | 0.026039 | **0.014787** | 差距缩小0.011252 |

旧报告中的X3单图Dice=0.853920、IoU=0.771766来自另一评估入口；旧导出mask按本次统一口径复算得到0.854101/0.771470。主表使用统一复算数值，避免与新版本的导出mask指标混用。

两个版本的B7 Dice均精确复现旧记录。逐图对比新版相对旧版：25张改善、50张持平、25张下降；平均Dice差-0.002792，配对bootstrap 95%区间[-0.016145,+0.007856]（seed2026，10000次）。差异小且区间跨0，不能据此宣称某版稳定优于另一版。

Dice与IoU均为逐图算分再平均；宏平均的排序可能不同，因此新版IoU略高与Dice略低并不矛盾。

委员会范围由旧`audit/committee_route_scores.jsonl`的实际桥长3/4/5/6和两模式核实：382张×8=3056条记录。不能将旧委员会笼统记为14候选。

新流程还修复了S3的16位软标签/像素权重读取问题，训练脚本也有版本差异。因此这是两套已完成流程的比较，不是只改变“是否保留PC”的严格单因素消融。

## 判断

1. 在无学生Router阶段，新TP-only基线更好。
2. 经过学生训练后，新版X3单图表现更好，但B7最终Dice尚未超过旧双路线主线。
3. 删除PC使候选Oracle降低，说明旧PC提供了TP候选池没有的一部分好mask；新版较小的Oracle gap不能单独证明其评分器更强，因为候选池也变了。
4. 当前保留两版记录：无学生基线为TP Router 0.885433；本轮TP-only学生结果为0.892639；历史SAM3-base双路线X3-best+B7为0.895432。

旧X3-final+B7的0.897684属于诊断结果，不能用test较高为由替换validation-selected主线。e33/LoRA结果使用不同传播模型，也应单列比较。

原始复算数据保存在新主线目录的`comparison_with_dual_route.json`及`comparison_with_dual_route_per_target.jsonl`。
